# Vallhund Cybernetics — public site

Source for **https://vallhundcybernetics.com** (GitHub Pages).

- `index.html` — company page: a three-stage commercial plan. Stage 01 is Vallhund Microbots™ (shipping). Stage 02 is hands, embodied AI, and power. Stage 03 is concept architecture only.
- `microbots/index.html` — Vallhund Microbots™, the consumer desk-robotics line (Boozy™ and Marshmallow™).
- `founders/index.html` — founders and contact.
- `arm.html` — interactive 3D model of the Vallhund manipulation module (open-source SO-ARM101 arm, 5 DOF + gripper). CAD © TheRobotStudio, Apache-2.0; viewer built with three.js and urdf-loader (MIT).
- `CNAME` — custom domain.
