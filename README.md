# Vallhund — BattleBuddy Project

Interactive 3D model of the Vallhund manipulation module: the open-source SO-ARM101 arm
(5 DOF + gripper, 6× STS3215 bus servos, ~400 mm practical reach), rendered directly from
the official engineering CAD.

Part of **BattleBuddy** — an assistive robotic companion built in Fayetteville, NC by a
service-disabled veteran. A smart dog for the home: it follows and escorts, picks things up
off the floor and hands them over, notices changes in routine and checks in — escalating to
a chosen friend or family member, not 911.

**Live site:** https://vallhundcybernetics.com
